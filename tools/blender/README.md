# tools/blender: scripted 3D assets

Every model in Rush Job except the Meshy characters is generated by a script here and run in headless Blender. To change a model, edit its script and rebuild. Nothing is hand-modelled, and no .blend files are kept.

## Run

```
py tools/blender/build.py               # all libraries
py tools/blender/build.py kit glint     # some (names are <lib> from <lib>_build.py)
py tools/blender/build.py --no-preview  # skip renders: GLB + manifest only, faster
```

Requirements: Blender 5.2 at `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe` (override with the `RJ_BLENDER` environment variable) and Python 3 with Pillow (`py -m pip install pillow`) for the contact sheets.

Each `<lib>_build.py` script produces:

| Output | What |
| --- | --- |
| `assets/models/<lib>.glb` | The library: one top-level node per piece |
| `reference-images/previews/<lib>_sheet.png` | Labelled contact sheet with triangle counts (red = over the 2k prop budget). **This is what Kyle reviews.** |
| `reference-images/previews/<lib>/*.png` | One render per piece (not committed) |
| `reference-images/previews/<lib>/manifest.json` | Pieces, triangles, children, glTF bounds (committed) |
| `reference-images/previews/kit_demo.png` | A small shop corner built from the kit, seen from the game camera |

After a build, `assets_table.py` regenerates the asset table in `ASSETS.md`.

## Libraries

| Script | GLB | Contents |
| --- | --- | --- |
| `kit_build.py` | `kit.glb` | Walls, doorways, windows, shopfront, doors, floors, ceiling, curb, restricted trim |
| `props_build.py` | `props.glb` | Shared heist props: camera, keypad, card reader, safe, bags, van, office furniture |
| `glint_build.py` | `glint.glb` | Glint & Sons: display cases, counter segments, shop sign |
| `chars_build.py` | `char_player/guard/civilian.glb` | Stand-in rigged humanoids with the full clip set |

## Writing a build script

```python
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import rj

p = rj.Piece("crate", kind="prop", cells=(1, 1), note="shows up in ASSETS.md")
p.box(-0.4, -0.4, 0, 0.4, 0.4, 0.8, "Wood")          # x0 y0 z0 x1 y1 z1 (Blender Z-up), material
lid = p.child("crate_lid", pivot=(0, 0.4, 0.8))       # moving/hideable part, origin = hinge
lid.box(-0.4, -0.8, 0, 0.4, 0, 0.05, "WoodDark", bottom=True)
p.view = dict(elev=35, azim=-30)                      # preview camera (optional)
rj.finish("crates", [p])                              # file must be named crates_build.py
```

- Build in Blender coordinates: Z-up, front = −Y. The exporter turns this into glTF Y-up with front = +Z.
- Primitives: `box`, `cbox` (centred), `cyl` (any axis, frustum via `r2`), `prism` (extrude a 2D outline), `quad`, `face`, `rj.text_into`. `with p.at(loc, rz=deg):` transforms whatever is added inside it.
- `box` drops the bottom face of anything sitting on the floor. `skip=('-x', '+x')` drops faces that a neighbour hides.
- Materials are names from `rj.MATS` (shared `RJ_*` list). Add new colours to `PAL` and `MATS` and to `reference-images/STYLE.md`, never inline.
- The texture is `assets/textures/rj_tile.png` (`textures/make_tile.py`). A material with `tex=(su, sv)` gets world-scaled box UVs.

## Compression (pending)

`build.py` meshopt-compresses each GLB in place with `gltfpack -cc -kn -km -ke` when `gltfpack` is on PATH. It isn't installed yet. Two ways to add it: the `gltfpack` npm package (a dev dependency in `package.json`, which the systems session owns), or the standalone binary from the meshoptimizer releases. Until then the GLBs ship uncompressed. That's fine for now: everything totals under 1 MB.
